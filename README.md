# ALL DAY

ALL DAY is a landscape kitchen-line trainer. Read tickets, bread and cook food
using the menu's real timings, then plate and send orders. Tips buy equipment
and XP tracks career progression.

```sh
npm ci
npm run dev
npm test
npm run build
```

Vite serves the game and produces a static build in `dist/`. The app uses
`index.html` for its overlays, `src/line-game.js` for shift actions and saved
progress, `src/sim/` for cooking and ticket rules, and `src/scene/` for the kitchen
canvas and input.

See [the project brief](docs/PROJECT.md) for the training goals.
